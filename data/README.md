# Data access and provenance

## Included files

`data/derived/` contains only non-disclosive aggregate outputs generated by the validated analysis workflow. No DHS microdata or frozen raw routine-data records are distributed in this repository.

## Rwanda DHS 2019-20

The RDHS worked examples use the Rwanda 2019-20 Individual Recode dataset corresponding to `RWIR81DT.ZIP`. DHS microdata are access-controlled. Users must obtain their own authorised access from The DHS Program and keep the source dataset outside the repository.

The analysis expects a locally prepared `RWIR81DT.rds` file supplied through the `RDHS_IR_RDS` environment variable. The validation script exports aggregate results only.

Official report citation: National Institute of Statistics of Rwanda (NISR) [Rwanda], Ministry of Health (MOH) [Rwanda], and ICF. 2021. Rwanda Demographic and Health Survey 2019-20 Final Report. Kigali, Rwanda, and Rockville, Maryland, USA: NISR and ICF. DHS publication FR370. Official publication page: https://dhsprogram.com/publications/publication-FR370-DHS-Final-Reports.cfm

## Routine DHIS2 demonstration extract

The routine-data example uses a frozen DHIS2 demonstration-data extract named `dhis2_indicator.csv`. The raw CSV is not redistributed while source-specific redistribution terms remain under review.

Validated source provenance was reconstructed and independently verified against the frozen analytical input. The example uses the "ANC 1 Coverage" indicator (DHIS2 indicator UID Uvn6LCg7dVU) from the Sierra Leone DHIS2 demonstration database. The reconstructed provenance identifies the DHIS2 Analytics API and organisation-unit UID ImspTQPwCqd; the hash-matched frozen analytical input contains observations for 13 districts across monthly periods. The historical extraction timestamp has not been recovered. Official DHIS2 demo information: https://dhis2.org/demo/

The validated frozen input has SHA-256:

`34412B3539CCDFAE5E71DC56B007A315282D545722F75369A33ABC45EEC328AC`

Users possessing the validated source file can provide its local location through the `DHIS2_FILE` environment variable.

Diagnostic values above 100 or below 5 are retained as observations requiring investigation. They are not automatic exclusion or correction rules.
